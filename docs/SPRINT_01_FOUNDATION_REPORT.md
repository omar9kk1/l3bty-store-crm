# تقرير Sprint 01 — تأسيس تطبيق L3BTY

تاريخ التنفيذ: 5 أغسطس 2026  
نطاق المهمة: إنشاء أساس Next.js فقط، من دون وحدات أعمال أو مصادقة أو قاعدة بيانات.

## النتيجة

تم إنشاء تطبيق إنتاجي مستقل داخل `l3bty-app` باستخدام App Router وTypeScript وTailwind CSS وESLint، مع Root Layout عربي من المصدر (`lang="ar"` و`dir="rtl"`). لم يتم تضمين الـPrototype داخل التطبيق، ولم يُنسخ Claude Runtime، ولم تبدأ أي ميزة أو خدمة أو تكامل Supabase.

## الخطوط

الخط العربي المعتمد في الوثائق والـPrototype هو **IBM Plex Sans Arabic** بالأوزان 400 و500 و600 و700. وللنص اللاتيني والأرقام يُستخدم **Plus Jakarta Sans** بالأوزان نفسها.

تم تحميل الخطين عبر `next/font/google`. يقوم Next.js بجلب ملفات الخط وقت البناء ثم يخدمها ذاتيًا من التطبيق؛ لا يرسل المتصفح طلبات إلى Google وقت التشغيل. لم تُنسخ ملفات خطوط محلية غير موجودة أو غير مصرح بها، ولذلك بقي `public/fonts` محجوزًا وفارغًا.

القيد التشغيلي الوحيد: يحتاج أول بناء نظيف إلى اتصال شبكي حتى يتمكن `next/font` من جلب ملفات الخط. بعد البناء تصبح الخطوط أصولًا محلية ضمن مخرجات Next.js.

## Root Layout وRTL

- `html` مضبوط على `lang="ar"` و`dir="rtl"` مباشرة في المصدر.
- metadata الأولية: `L3BTY | لعبتي` ووصف عربي.
- الخط العربي هو الخط الأساسي، مع فصل خط الأرقام اللاتينية.
- استُخدمت CSS logical properties في التخطيط والحواف والمسافات.
- مُنع التمدد الأفقي على مستوى `html` و`body`.
- أضيف `focus-visible` واضح، واحترام `prefers-reduced-motion`، وشريط تمرير هادئ مع بقاء التمرير متاحًا.

## صفحة Foundation

الصفحة الرئيسية الحالية ليست Dashboard. وهي تعرض فقط:

- اسم لعبتي وعنوان تأسيس التطبيق.
- مؤشر أن RTL مفعل من المصدر.
- عينات Design Tokens والألوان.
- مثال Typography عربي مع أرقام لاتينية.
- أمثلة أزرار وحالات Status غير تفاعلية تجاريًا.
- إشارة نصية إلى أن App Shell هو المهمة التالية.

## فحص المقاسات

تم الفحص في المتصفح المدمج على المقاسات المطلوبة:

| المقاس المطلوب | النتيجة |
| --- | --- |
| 1440×900 | RTL صحيح، شبكة الألوان والتخطيط سليمان، لا قص ولا تمدد أفقي |
| 1024×768 | RTL صحيح، الانتقال إلى تخطيط التابلت سليم، لا قص ولا تمدد أفقي |
| 390×844 | RTL صحيح، التخطيط عمود واحد، الأزرار والنصوص بلا تداخل، لا تمدد أفقي |

تحققت الفحوصات البرمجية في المتصفح من `lang=ar` و`dir=rtl`، تحميل IBM Plex Sans Arabic وPlus Jakarta Sans، خلفية `#ECECEC`، وعدم وجود عناصر تتجاوز عرض الصفحة. أداة المتصفح المدمج أبلغت عن فرق بكسل CSS واحد في بعض المحاكاة (1441 بدل 1440 و391 بدل 390)، من دون ظهور overflow أو تأثير على نقاط الاستجابة.

## التحذيرات والملاحظات المتبقية

- لا توجد مشكلة وظيفية متبقية في Foundation.
- يتطلب البناء النظيف اتصالًا شبكيًا لجلب الخطين عبر `next/font/google` كما سبق.
- ملفات SVG الافتراضية داخل `public` غير مستخدمة حاليًا، وتم إبقاؤها لأن حذفها ليس مطلوبًا في هذه المهمة.
- لا توجد Sidebar أو Header نهائي أو Mobile Navigation أو أدوار أو صلاحيات أو Features أو Services أو Mock business data أو Auth أو Supabase، التزامًا بنطاق المهمة.
